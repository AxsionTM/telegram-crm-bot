# 📬 Telegram CRM Bot

Полноценная CRM-система внутри Telegram-бота.

Бот принимает заявки от клиентов, сохраняет их в Excel, отправляет уведомления администратору в Telegram и на Email, а также предоставляет удобную админ-панель для управления заявками, статистикой и настройками.

Проект создан как учебный и портфолио-кейс по автоматизации бизнес-процессов через Telegram.

---

## ✨ Возможности

### Для клиентов
- 📝 Оформление заявки пошагово: имя → телефон → описание
- ℹ️ Раздел «Контакты»
- ❌ Возможность отменить оформление заявки

### Для администратора (`/admin`)
- 📋 Список заявок с пагинацией (по 3 на странице, сначала новые)
- 🔍 Поиск по ID, имени и телефону
- 🎯 Фильтрация по статусу
- 🔄 Смена статуса заявки в один клик
- 🗑 Удаление заявки
- 📊 Статистика по всем статусам
- 📥 Экспорт базы в Excel-файл
- 🧹 Полная очистка базы (с подтверждением)
- 🔔 Гибкие уведомления: можно отдельно включить/выключить Telegram и Email
- 📧 Просмотр SMTP-настроек
- 👤 Просмотр текущего администратора

## 🏗 Архитектура проекта

Бот построен по слоям — каждый слой отвечает только за свою задачу:

```text
Telegram User
     │
     ▼
┌─────────────┐
│  Handlers   │  ← принимают команды, кнопки, текст
└──────┬──────┘
       │
       ▼
┌─────────────┐
│  Services   │  ← бизнес-логика (заявки, уведомления, фильтры)
└──────┬──────┘
       │
       ▼
┌─────────────┐
│  Storage    │  ← Excel + JSON-настройки
└─────────────┘
```

### Слои подробнее

**1. Handlers (`app/handlers/`)**  
Обрабатывают входящие события:
- `/start`, `/admin`
- диалог создания заявки
- все inline-кнопки админ-панели
- текстовый поиск

**2. Keyboards (`app/keyboards/`)**  
Собирают кнопки:
- главное меню пользователя
- админ-панель
- список заявок, поиск, фильтры
- карточка заявки
- настройки и переключатели уведомлений

**3. Services (`app/services/`)**  
Бизнес-логика:
- `application_service` — фильтрация и пагинация заявок
- `excel_service` — создание / обновление / удаление заявок
- `notification_service` — центр уведомлений
- `telegram_service` — отправка сообщений админу
- `email_service` — отправка писем
- `filter_service` — состояние фильтров пользователя

**4. Storage (`app/storage/`)**  
Работа с данными:
- `excel_storage` — чтение и запись `applications.xlsx`
- `settings_storage` — сохранение настроек уведомлений в JSON

**5. Models (`app/models/`)**  
Простые модели данных:
- `Application` — заявка
- `FilterState` — текущие фильтры админа

**6. States (`app/states/`)**  
Состояния ConversationHandler для пошагового ввода заявки.

**7. Utils (`app/utils/`)**  
Вспомогательные вещи:
- форматтеры текста
- callback-константы
- валидаторы
- логгер

## 🔄 Как работает бот

### Создание заявки (клиент)

1. Пользователь нажимает **📝 Оставить заявку**
2. Бот по очереди спрашивает имя, телефон и описание
3. Данные сохраняются в Excel (`app/data/applications.xlsx`)
4. Срабатывает `notification_service`:
   - если включены Telegram-уведомления — админ получает сообщение в личку
   - если включены Email-уведомления — уходит HTML-письмо
5. Клиенту показывается подтверждение

### Работа администратора

1. Админ пишет `/admin`
2. Бот проверяет `OWNER_ID` из `.env`
3. Открывается панель:
   - заявки
   - статистика
   - настройки
4. Все действия идут через inline-кнопки и callback-обработчик

### Статусы заявки

| Статус | Значение |
|--------|----------|
| 🟢 Новая | Только что создана |
| 🟡 В работе | Взята в обработку |
| ✅ Завершена | Успешно закрыта |
| ❌ Отменена | Отклонена |

## 🚀 Быстрый старт

### 1. Клонируй репозиторий

```bash
git clone https://github.com/AxsionTM/telegram-crm.git
cd telegram-crm
```

### 2. Создай виртуальное окружение

```bash
python -m venv venv

# Windows
venv\Scripts\activate

# Linux / macOS
source venv/bin/activate
```

### 3. Установи зависимости

```bash
pip install -r requirements.txt
```

### 4. Создай файл `.env`

В **корне проекта** создай файл `.env` со следующим содержимым:

```env
BOT_TOKEN=1234567890:ABCDEF_your_bot_token_here
OWNER_ID=7581461096

EMAIL_LOGIN=your_email@gmail.com
EMAIL_PASSWORD=your_gmail_app_password
EMAIL_RECEIVER=your_email@gmail.com

SMTP_SERVER=smtp.gmail.com
SMTP_PORT=587
```

#### Где взять данные

| Переменная | Что это | Как получить |
|------------|---------|--------------|
| `BOT_TOKEN` | Токен Telegram-бота | [@BotFather](https://t.me/BotFather) → `/newbot` |
| `OWNER_ID` | Твой числовой Telegram ID | [@userinfobot](https://t.me/userinfobot) |
| `EMAIL_LOGIN` | Почта, с которой отправляются письма | Твой Gmail |
| `EMAIL_PASSWORD` | Пароль приложения Google | [App Passwords](https://myaccount.google.com/apppasswords) |
| `EMAIL_RECEIVER` | Куда приходят уведомления | Обычно тот же email |
| `SMTP_SERVER` | SMTP-сервер | Для Gmail: `smtp.gmail.com` |
| `SMTP_PORT` | Порт SMTP | Для Gmail: `587` |

> ⚠️ Обычный пароль от Google-аккаунта **не подойдёт**.  
> Нужен именно **App Password** (пароль приложения).

### 5. Запусти бота

```bash
python main.py
```

При успешном запуске в консоли будет:

```text
✅ Telegram CRM Bot started.
```

## 📱 Как пользоваться

### Клиент
1. Отправь боту `/start`
2. Нажми **📝 Оставить заявку**
3. По очереди введи имя, телефон и описание
4. Получи подтверждение о создании заявки

Путь в боте: **Настройки → Уведомления**

## 🔐 Безопасность

- `.env` содержит секреты и **не должен** попадать в Git
- В репозитории есть только `.env.example` (шаблон без реальных данных)
- Команда `/admin` доступна только пользователю с `OWNER_ID`
- Excel-база и локальные настройки тоже игнорируются Git
